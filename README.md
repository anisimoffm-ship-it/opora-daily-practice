# Опора

Мобильное приложение для развития внутренней опоры через короткую ежедневную практику.

Основные продуктовые принципы, тон общения, правила психологической безопасности и инструкции для AI-агентов собраны в [библиотеке продукта](docs/product-library/README.md).

## Что есть в приложении

- Один ежедневный ритуал продолжительностью около 60-90 секунд
- Восемь практик: от строгого голоса и проверки фактов до собственных ориентиров и сравнения ожиданий с реальностью
- Короткая пауза и подбор одной практики по текущему состоянию
- Ответ письменно или про себя без сохранения личного текста
- Спокойное завершение без серий, баллов и оценки ответа
- Необязательные локальные напоминания с выбором времени и звучания
- Android-прототип и упрощённая web-оболочка для быстрой проверки сценариев

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm run start-local
```

Откройте [http://localhost:3000](http://localhost:3000).

Также можно использовать файлы запуска:

- Windows: дважды нажать `run.bat`
- macOS: дважды нажать `run.command`

Если macOS не запускает файл из-за прав, выполните:

```bash
chmod +x run.command
```

## Сборка

```bash
npm run build
```

## Проверка кода

```bash
npm run lint
```

## iOS и Android

Проект настроен для Capacitor. Команда повторной web-сборки и синхронизации:

```bash
npm run mobile:sync
```

Инструкции для Xcode, Android Studio и тестирования на устройствах находятся в [docs/mobile-build.md](docs/mobile-build.md).

## Структура

```text
src/
  app/                 # Страницы Next.js App Router
  components/          # UI и клиентские сценарии
  lib/                 # Контент, типы, хранилища и бизнес-логика
```

Контент состояний и восьми практик находится в `src/lib/daily-ritual.ts`, основной сценарий — в `src/components/ritual/daily-ritual.tsx`.
