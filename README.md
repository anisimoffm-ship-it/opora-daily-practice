# Опора

Мобильное веб-приложение для развития внутренней опоры. Пользователь быстро записывает автоматическую мысль, а затем тренирует один небольшой навык на материале этой мысли.

## Что есть в приложении

- Главный экран с шестью направлениями: критик, самоподдержка, тревожная мысль, ошибки, смелый шаг и внутренняя опора
- Быстрая запись мысли за короткий сценарий: текст, ситуация, эмоция и вера 0-100%
- Входящие мысли со статусами `Новая`, `В процессе`, `Разобрана`
- Карточка мысли с историей тренировок и итоговыми формулировками
- Шесть навыков MVP, каждый выращивает один лист в дереве навыков
- Анализ повторяющихся мыслей и предложение путешествия из пяти тренировок
- Локальное хранение данных в браузере
- Локальные уведомления, которые учитывают последние мысли и тренировки

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm run start-local
```

Откройте [http://localhost:3000](http://localhost:3000).

Также можно использовать файлы запуска:

- Windows: дважды нажать `run.bat`
- macOS: дважды нажать `run.command`

Если macOS не запускает файл из-за прав, выполните:

```bash
chmod +x run.command
```

## Сборка

```bash
npm run build
```

## Проверка кода

```bash
npm run lint
```

## Структура

```text
src/
  app/                 # Страницы Next.js App Router
  components/          # UI и клиентские сценарии
  lib/                 # Контент, типы, хранилища и бизнес-логика
```

Ключевая новая модель находится в `src/lib/thought-storage.ts`, а контент шести навыков - в `src/lib/thought-content.ts`.
